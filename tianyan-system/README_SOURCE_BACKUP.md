# 天眼系统源码备份

本目录是天眼系统的源码、规则、测试与文档快照，用于版本管理。

## 包含范围

- 每日更新唯一入口与节点化调度程序。
- 数据源采集和增量入库程序。
- 数据结构、字段映射、业务规则和数据稽核规则。
- 页面模板及前端源码。
- 单元测试、工程规范和运行说明。

## 不包含范围

- SQLite 主库、更新状态库及数据库备份。
- 原始采集、标准化数据、运行日志、报告包及页面发布结果。
- App 登录态、Cookie、Session、DPAPI 密钥和真实 API Key。
- APK、ADB/Platform Tools 二进制、截图、抓包和反编译产物。

仅克隆本源码不能恢复当前完整历史数据，也不能直接通过迁移工作区首次初始化。换机运行还需要经校验的数据迁移包，并在新电脑重新完成依赖安装、设备授权和必要的 App/API 登录。

生产入口为根目录的 `00_每日数据更新并发布_唯一入口.bat`。正式执行前应阅读 `AGENTS.md`、`README_AI.md` 和 `程序代码/文档/项目规范/可迁移运行工作区与程序更新说明.md`。
