# 可迁移运行工作区与程序更新说明

## 目标

迁移包用于在另一台 Windows 电脑上定时执行：

1. 当前每日 DAG 已启用的天天投顾、广发基金、广发证券和且慢增量采集。
2. 基金净值、策略业绩、仓位、调仓和基础信息更新。
3. 数据稽核、成功数据库滚动备份、正式结果刷新。
4. 最小发布集提交、GitHub 推送和 Pages 验证。

工作区可放在任意盘符和任意目录层级。项目配置中的路径必须是相对工作区根目录的路径。

## 开发工程入口

- `构建增量运行迁移包.bat`：生成完整迁移目录。
- `上传开发工程到Git.bat`：人工审核开发代码并推送 `investment-advisor-monitor/code`。
- `00_每日数据更新并发布_唯一入口.bat`：开发机原有扁平目录的兼容入口。

迁移包构建器会拒绝以下状态：

- 每日更新仍在运行。
- 使用 Git 代码源时，运行所需程序存在未提交改动或当前 `HEAD` 与 `origin/code` 不一致。
- 使用 Syncthing 工作树快照时，代码路径便携性检查不通过。
- 可执行脚本中仍存在原电脑绝对路径。
- 数据库不完整或缺少最近完整的天天/广发标准化基线。

首次制作前先运行 `上传开发工程到Git.bat /ReviewOnly` 审核范围，再由人工确认提交并推送。推送完成后执行 `构建增量运行迁移包.bat`；可把目标目录作为第一个参数传入，不传时输出到开发目录下的 `迁移产物`。

## 迁移内容

必须携带：

- SQLite 主库、原始快照索引库和更新状态库。
- 天天、广发基金、广发证券、广发证券历史货架和且慢的最近完整标准化基线。
- 设备缓存、基金穿透缓存、广发协议缓存、最新基准文本，以及且慢最近一次已验收历史基线。
- 当前受控程序工作树快照；反编译产物、探测截图、历史评估和调试工具不进入运行包。
- 从 `invest/main` 浅克隆的最小发布仓库。
- 正式页面和最小发布集均由主库重建；已明确移除的月报内容不作为迁移依赖，也不复制月报静态种子。
- 最近成功摘要、稽核报告、文件校验和迁移清单。

不携带：

- 开发工程和正式结果仓库的历史 `.git`。
- 历史失败批次、调试截图、全量日志、旧版报表归档和正式结果仓库历史。
- 已入库的全量历史标准化文件和基金净值原始响应。
- 原电脑的 Python 虚拟环境；虚拟环境含原机用户目录和绝对路径，必须在新电脑本地创建。

## 机器绑定凭据

- `本机配置/qieman_stargate_api_key.dpapi` 使用 Windows DPAPI `CurrentUser` 加密。迁移包可携带密文用于同机副本验证，但换电脑或换 Windows 用户后不能把“文件存在”视为可用，必须重新进行且慢官方短信授权并在目标机生成新密文。
- 南方基金当前不在每日 DAG，私募相关账号和凭据不属于本迁移包。
- 不把密码、Cookie 明文或浏览器用户目录复制到迁移包。

## 新电脑首次验收

1. 执行迁移包根目录的 `安装或检查运行环境.bat`；脚本会检查并按需安装 Python 3.12、Node.js 和 Git，并在 `运行环境/python` 创建独立虚拟环境。
2. 若服务器不能使用 winget，按脚本错误提示手工安装缺失程序后重跑。
3. 配置 Git Credential Manager，确保 `invest` 与 EdgeOne 配置对应的发布远端具备推送权限。
4. 在配置的实体手机上登录天天基金 App，并完成 USB 调试及 ADB 授权；生产运行不再安装或配置模拟器。
5. 核对 `本机配置\runtime.local.json` 中的实体手机序列号；无线 ADB 的 IP/端口在换电脑后可能需要重新配对，生产链路不得启用 MuMu。
6. 执行 `首次初始化与检查.bat`。该步会建立运行目录连接、运行 SQLite `quick_check`、检查依赖/设备/Git/Pages，并创建首次成功基线备份。
   初始化还会逐文件校验 `迁移基线/checksums.sha256`，大数据库和完整页面基线会使这一步持续一段时间，控制台会持续显示已校验文件数和读取容量。
7. 手工执行一次 `00_每日数据更新并发布_唯一入口.bat`。
8. 连续成功两次后，再接入用户自行配置的外部任务调度。

## 程序更新和回退

新电脑不允许直接修改 `程序代码`。程序更新流程为：

1. 开发机审核、提交并推送 `code` 分支。
2. 新电脑确认每日任务未运行。
3. 执行 `更新程序代码.bat`。
4. 脚本只允许快进更新，并执行路径、语法、单元测试和数据库版本兼容检查。
5. 验证失败自动恢复旧提交。需主动回退时执行 `回退上一程序版本.bat`。

程序更新和每日任务使用独立互斥锁，不会同时执行。数据库、采集数据、结果、本机配置和发布仓库不参与程序代码更新。
