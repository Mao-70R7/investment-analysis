# 非生产工具

`merge_verified_southern_batch.py` 仅用于把已经过专项稽核的南方基金标准化批次回放到生产库。脚本会同时获取 `daily_update` 与 `main_db_write` 资源锁，先执行 SQLite 在线备份和 `quick_check`，再按指定批次事务入库并逐项核对行数；它不属于每日 DAG，也不会执行采集或发布。

本目录用于放置研究验证、一次性诊断和离线分析程序，不进入 `pipeline.json`，不得被每日生产节点依赖。

工具转为生产能力前，必须迁入明确责任节点的 `src` 或 `_共享组件`，补齐节点契约、测试、进度、幂等和结果校验。

当前保留的非生产入口包括开发工程 Git 上传和本地静态站点启动；它们不参与每日更新，也不随迁移运行包自动执行。

`migrate_advisor_collection_packages.py` 仅用于把中欧、南方独立验证包映射到迁移运行布局。它会备份旧渠道输出、复制原始与标准化批次并生成 SHA-256 清单，不写主数据库、不生成页面，也不进入每日 DAG。
