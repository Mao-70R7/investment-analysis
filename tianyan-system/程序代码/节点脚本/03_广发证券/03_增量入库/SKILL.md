# 广发证券财富管家增量入库

节点ID：`gfsec_fima_load`

## 目标

只消费同一运行批次且已通过 `gfsec_fima_gate` 的标准化数据，在 `main_db_write` 资源锁内事务替换主库中的 `gfsec_fima` 渠道数据。

## 安全规则

- 不重建主库，不重置其他渠道。
- 采集批次与门禁批次必须一致。
- 入库后策略数必须与采集摘要一致，否则节点失败。
- 在事务提交前逐 ID 核对目录策略和目录新增策略均已写入 `策略信息`；缺任一 ID 则回滚。
- 写入失败时事务回滚并保留原有渠道数据。

## 手工复跑

```powershell
& ".\00_每日数据更新并发布_唯一入口.bat" node gfsec_fima_load --run-id <run_id>
```
