# 广发证券财富管家批次验收

节点ID：`gfsec_fima_gate`

## 目标

验证财富管家本批次来源一致性、计划与处理计数恒等式、成功失败计数恒等式、策略库存保留率和核心接口覆盖率，通过后才允许主库加载。

## 门禁规则

- 底层组合：计划数 = 已处理数 = 成功数 + 失败数。
- 产品实例：计划数 = 已处理数 = 成功数 + 失败数。
- 底层组合成功覆盖率默认不低于 95%。
- 策略主数据、日度业绩、基金级当前模型仓位和调仓接口核验均须通过渠道覆盖检查。
- 官方调仓列表全部返回空时允许通过，但必须记录“已核验无事件”的非阻断警告。
- 机构、策略、目标盈期次目录必须证明完整，且目录中的每个产品实例均已进入本批策略主表；任一新增 ID 遗漏均拒绝覆盖旧库。

## 手工复跑

```powershell
& ".\00_每日数据更新并发布_唯一入口.bat" node gfsec_fima_gate --run-id <run_id>
```
