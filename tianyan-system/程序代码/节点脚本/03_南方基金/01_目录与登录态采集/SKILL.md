# 南方基金目录与登录态采集

节点 ID：`southern_collect`

## 目标

手工启用南方专项更新时，通过官方公开 H5 的 `IA049 + IA050（全量及分类）+ IA028` 并集重建司南投顾目录，再使用南方基金网上交易的持久化登录态获取每个策略的基础信息、费率、成立以来业绩、基准曲线、当前精确基金仓位和成立以来每日精确基金仓位。该节点自 2026-08-16 起不进入每日 DAG。

所有策略必须合并为同一个调度 `runId` 下的完整快照，禁止把单策略文件当作渠道最新批次。登录接口的收益率单位明确标记为 `percent_point`；历史持仓只发布 `strategy_fund_snapshot_history`，不再复制兼容别名。

## 安全边界

- 公开目录采集和网页登录采集不使用 ADB，不占用 `device` 锁，可与天天投顾设备节点并行。
- 采集器允许当前调度自身的 `daily_update.lock`，但遇到其他批次锁或 `main_db_write.lock` 必须中止。
- 浏览器档案位于 `运行状态/state/southern-profile`，不得写入发布集或 Git。
- 账号和密码仅允许通过进程环境或后续 Windows 凭据安全读取，不写入脚本、日志、原始响应或标准化文件。
- 无人值守运行优先读取 `本机配置/southern_login.dpapi`。该文件必须由 `configure_southern_dpapi_credentials.py` 交互生成，使用 Windows 当前用户绑定的 DPAPI 加密，禁止把账号密码放进命令行参数。
- 登录页账号输入框默认禁用时，采集器先等待官网异步绑定 `#lableLT` 点击处理器，再调用元素原生 click 解锁；不得直接移除字段属性绕过官网表单逻辑。
- 每次启动必须关闭浏览器档案恢复的旧标签页，避免旧 `SECURE_TOKEN` 与本次会话并发访问；登录成功后复用当前一次性司南入口，通过官网“立即开启”链接建立投顾上下文，禁止重载同一个入口令牌。
- 账号密码可以从 DPAPI 自动提交；官网触发短信、图形验证码、人脸或扫码二次验证时不得绕过，也不得自动请求验证码。节点返回 `auth_challenge_required` 及具体验证类型，旧南方数据保持不变。南方基金当前为手工专项更新渠道，不参与每日数据加工、稽核、备份和自动发布依赖；用户在专用浏览器档案完成一次官方验证后，手工专项运行可复用该持久登录态。
- 策略详情优先使用官网 `zxlc_buydetail` 入口；必须同时取得业务成功且非空的 `webIAqueryCombInfo` 与 `webIAcombFundMarketQuery`，缺失或业务错误必须返回非零，禁止仅凭 HTTP 200 判成功。

## 必需验收

- 公开目录与登录态实际采集策略 ID 完全一致。
- 每个策略具备成立以来业绩、当前基金仓位和历史每日基金仓位。
- 当前及每个历史仓位快照权重合计为 100%（容差 0.05）。
- 历史基金代码必须解析出基金名称；缺失即阻断。
- 官方精确基准拆分允许源端确实未披露的策略以 warning 保留，禁止主观补值。
- 本批任一必需验收项失败时禁止写入南方新批次，但应继续使用主库中的上一成功版本完成其他渠道发布。

## 输出

- `采集数据/normalized/southern/<entity>/<runId>/<runId>.jsonl`
- `采集数据/normalized/southern/collection_summary/<runId>/<runId>.json`
- 节点运行目录内精确采集结果和 `southern_isolated_audit.json`
