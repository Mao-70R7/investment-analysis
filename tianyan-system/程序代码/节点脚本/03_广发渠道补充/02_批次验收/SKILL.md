# 广发证券历史接口批次验收

节点ID：`gf_supplemental_gate`  
执行入口：`run.ps1`  
超时：`600` 秒  
资源锁：`无`

## 目标

以独立节点执行“广发证券历史接口批次验收”，形成可重试、可验证、可追溯的故障边界。

## 输入

- 工作区根目录、运行批次ID和节点运行目录。
- 上游节点通过校验的结果及统一运行环境变量。

## 输出

- 原子写入 `node_result.json`，并在尝试目录保留 `console.log` 与 `artifacts.json`。
- 节点业务输出：门禁结果及本轮允许入库的广发证券来源清单。
- 结果必须包含状态、退出码、输入指纹、输出水位、计数、警告、错误、日志和校验结论。

## 依赖节点

gf_supplemental_collect

## 业务口径

检查广发证券历史接口的策略数量、库存留存和业绩覆盖；推荐基金清单不得当成持仓。

## 进度单位

`个渠道`。长任务必须持续输出已完成数量、总数和当前动作。

## 重试策略

进程级最大尝试次数为 `1`。节点失败后由调度器按清单重试；不允许把输出校验失败当作成功。

## 幂等性

输入指纹一致、结果文件存在且验证通过时可跳过；重新执行不得制造重复业务记录。

## 失败影响

关键级别为 `optional`。失败只影响当前渠道；其他可用渠道继续执行。

## 手工复跑

```powershell
& ".\00_每日数据更新并发布_唯一入口.bat" node gf_supplemental_gate --run-id <run_id>
```

## 验证方法

检查节点结果中的退出码、`validation.status`、业务计数、水位和产物路径，不得只看进程退出码。

## 已知限制

无。
