# 股票行业映射补充表配置说明

文件：`config/股票行业映射补充表.csv`

用途：当东财 `stock/get` 或搜索接口无法识别个别 A股、港股、美股代码时，用人工复核后的行业映射补齐，不让这些股票长期停留在“未识别”。

字段说明：

- `股票代码`：必填，使用持仓明细里的原始代码，例如 `BRK.B`、`01088`、`300750`。
- `股票名称`：建议填写，页面和排障报告会展示。
- `市场代码`：可选，东财 QuoteID，例如美股 `105.NVDA`、港股 `116.01088`；不知道可以留空。
- `行业一级`：必填，标准一级行业或境外行业，例如 `信息技术`、`金融`、`石油石化`。
- `行业二级`：建议填写，保留更细行业。
- `东财行业`：可选，通常等于行业二级。
- `地区板块`：可选，例如 `A股`、`港股`、`美股`。
- `映射说明`：写清人工判断依据，便于内网和后续审计复核。

生效方式：

```powershell
python -X utf8 .\节点脚本\_共享组件\生产程序\回填股票行业映射.py --fetch-missing
python -X utf8 .\节点脚本\_共享组件\生产程序\规范化基金穿透数据.py
python -X utf8 .\节点脚本\_共享组件\生产程序\构建基金分类快照.py
```

日常增量流程会在 `规范化基金穿透数据.py` 中自动读取该补充表并回填。
