# Ai选策略模型配置说明

本目录只抽出“内网部署时需要调整的模型参数”。页面字段口径、筛选规则、调仓分析逻辑、基金分类逻辑都保留在正式前端资产和数据包里，不要在配置文件里重复维护。

## 配置文件

- `basic_data/config/模型服务配置.js`
  - 正式配置文件，内网迁移时主要改这个文件。
  - 当前默认值使用内网 `inner-deepseek` 服务。

- `basic_data/config/ai-strategy-local-config.js`
  - 兼容旧入口。
  - 通常不用改；如果历史部署已经改过这个文件，它仍会在 `模型服务配置.js` 之后加载，并覆盖同名字段。

## 当前配置：内网 DeepSeek 模型

当前默认配置如下：

```js
window.__AI_STRATEGY_LOCAL_CONFIG__ = {
  enabled: true,
  profile: "local",
  provider: "inner-deepseek",
  baseUrl: "http://10.89.189.109:8000/llmapi/v1",
  endpoint: "http://10.89.189.109:8000/llmapi/v1/chat/completions",
  model: "qwen35-397b-a17b",
  reasonModel: "",
  timeoutMs: 120000,
  mode: "hybrid-parse",
  apiKey: "<内网固定Key>",
  headers: {},
  rateLimitBackoffMs: 60000,
  responseFormat: false
};
```

该配置由浏览器直接调用内网模型，不再要求每次启动本机 Codex 桥接。固定 Key 已按当前内网部署要求写入正式配置文件。

GitHub Pages 使用 HTTPS，而当前内网接口是 HTTP。要从 GitHub Pages 稳定调用模型，内网模型网关需要提供 HTTPS，并正确配置 CORS 和 Private Network Access；不满足时页面会自动降级为本地规则筛选。

## 可选：本机 Codex 桥接模型

需要临时切回 Codex 时，在页面模型设置中选择“本机 Codex 桥接模型”，并启动：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\start_ai_strategy_codex_proxy.ps1
```

如果希望重启电脑后不用每次手动拉起桥接服务，在发布根目录运行一次：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\install_ai_strategy_codex_proxy_startup.ps1
```

该命令会注册当前 Windows 用户的计划任务 `AI Strategy Codex Proxy`，在用户登录时自动运行 `scripts/start_ai_strategy_codex_proxy.ps1`。启动脚本本身带健康检查；如果 `http://127.0.0.1:8787/healthz` 已经可访问，会直接退出，不会重复启动。

如需取消开机自启：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\uninstall_ai_strategy_codex_proxy_startup.ps1
```

浏览器页面不能直接启动本机 PowerShell 或 Node 进程，这是浏览器安全沙箱限制。页面只能做连通性测试、展示命令、复制命令；真正的启动需要由 Windows 计划任务或手动命令完成。

桥接服务健康检查地址：

```text
http://127.0.0.1:8787/healthz
```

Codex CLI 冷启动可能接近 60 秒，因此 Codex profile 保留 `120000` 毫秒超时。

## 可选：报表服务同源代理

如需切回报表服务同源代理，可把 `provider/baseUrl/endpoint/model` 改为：

```js
profile: "local",
provider: "same-origin-llm-proxy",
baseUrl: "/llmapi/v1",
endpoint: "/llmapi/v1/chat/completions",
model: "deepseek-v4-flash-inner",
timeoutMs: 45000,
responseFormat: false
```

浏览器只请求当前报表服务 `http://服务器IP:7676/llmapi/v1/chat/completions`。启动脚本会把该请求转发到上游模型服务，因此不需要修改模型服务器 CORS。

上游模型地址和鉴权在发布根目录的 `config/ai_strategy_proxy.env` 中配置：

```bash
AI_STRATEGY_UPSTREAM_BASE_URL=http://10.89.189.109:8000/llmapi/v1
AI_STRATEGY_UPSTREAM_API_KEY=<your-api-key>
AI_STRATEGY_UPSTREAM_AUTH_HEADER=Authorization
AI_STRATEGY_UPSTREAM_TIMEOUT=60
```

## 页面调试

`Ai选策略` 页面顶部有“模型设置与连通性测试”折叠区：

- 可临时编辑 base URL、endpoint、model、API Key、headers。
- 当前默认 base URL 为 `http://10.89.189.109:8000/llmapi/v1`；如果切到同源代理，base URL 保持 `/llmapi/v1`。
- “测试连通性”会用当前表单配置直接发起一次轻量 chat/completions 调用。
- “保存配置”会保存到当前浏览器 localStorage，不会改写静态配置文件。
- “恢复文件默认”会清除浏览器本地覆盖，回到 `模型服务配置.js`。

桥接服务会读取 `basic_data/config/模型服务配置.js` 中的 `codexBridge` 配置。临时调试时也可以继续使用环境变量覆盖，例如 `AI_STRATEGY_CODEX_MODEL`、`AI_STRATEGY_PROXY_PORT`。

## 字段说明

- `enabled`
  - 是否启用模型解析。
  - `false`：只使用本地规则解析，不请求模型。

- `provider`
  - 页面展示用的模型服务名称。
  - 当前默认填写 `"inner-deepseek"`。
  - 同源代理可填写 `"same-origin-llm-proxy"`。
  - 内网 DS 直连可填写 `"inner-ds-openai-compatible"`。

- `endpoint`
  - OpenAI 兼容接口地址，必须是 `/v1/chat/completions`。
  - 当前内网模型：`"http://10.89.189.109:8000/llmapi/v1/chat/completions"`。
  - Codex 桥接：`"http://127.0.0.1:8787/v1/chat/completions"`。
  - 同源代理：`"/llmapi/v1/chat/completions"`。

- `model`
  - 请求接口时传给后端的模型名。
  - 当前内网模型：`"qwen35-397b-a17b"`。
  - Codex 桥接：`"gpt-5.4-mini"`。
  - 同源代理内网 DS：`"deepseek-v4-flash-inner"`。
  - 其他模型以本地服务实际暴露的名称为准。

- `timeoutMs`
  - 浏览器等待模型返回的超时时间，单位毫秒。
  - Codex 桥接建议 `120000`，前端最大限制为 `120000`。
  - 内网 DS 推理较慢时建议 `90000`。

- `mode`
  - 建议保留 `"hybrid-parse"`。
  - 含义：先用本地规则解析，再让模型补充复杂中文自然语言意图。
  - 可设为 `"local-only"` 或 `"off"`，表示不请求模型。

- `apiKey`
  - 当前内网部署按要求在静态配置中固定填写。
  - Codex 桥接和同源代理模式下保持空字符串。

- `headers`
  - 额外 HTTP 请求头。
  - 示例：`{ "X-API-Key": "xxx" }`。

- `rateLimitBackoffMs`
  - 模型接口限流或失败后，页面暂停再次请求模型的时间，单位毫秒。

- `responseFormat`
  - 是否请求模型按 JSON object 返回。
  - 大多数 OpenAI 兼容服务支持；如果本地 DS 网关不支持 `response_format`，改为 `false`。

- `codexBridge`
  - 仅当前电脑 Codex 桥接脚本读取。
  - 内网 DS 直连时可以忽略。
  - 可配置端口、Codex 模型名、推理强度、桥接请求超时、并发数等。

## 迁移检查

1. 把整个结果目录同步到内网服务器。
2. 修改 `basic_data/config/模型服务配置.js`。
3. 用浏览器打开 `basic_data/ai-strategy.html`。
4. 页面顶部模型状态应显示新的 `model @ endpoint`。
5. 输入一句复杂中文筛选条件，例如“找近一年收益大于10%、最大回撤小于8%、不含黄金的稳健策略”，确认结果区显示“模型 xxx 已辅助解析”。
