# Ai选策略模型配置说明

本目录只抽出“内网部署时需要调整的模型参数”。页面字段口径、筛选规则、调仓分析逻辑、基金分类逻辑都保留在正式前端资产和数据包里，不要在配置文件里重复维护。

## 配置文件

- `basic_data/config/模型服务配置.js`
  - 正式配置文件，内网迁移时主要改这个文件。
  - 默认值保留当前电脑的 Codex 本地桥接模式。

- `basic_data/config/ai-strategy-local-config.js`
  - 兼容旧入口。
  - 通常不用改；如果历史部署已经改过这个文件，它仍会在 `模型服务配置.js` 之后加载，并覆盖同名字段。

## 当前电脑：保留 Codex 桥接模式

当前电脑默认配置如下：

```js
window.__AI_STRATEGY_LOCAL_CONFIG__ = {
  enabled: true,
  provider: "codex-cli-local-proxy",
  endpoint: "http://127.0.0.1:8787/v1/chat/completions",
  model: "gpt-5.4-mini",
  timeoutMs: 45000,
  mode: "hybrid-parse"
};
```

使用前启动桥接服务：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\start_ai_strategy_codex_proxy.ps1
```

桥接服务会读取 `basic_data/config/模型服务配置.js` 中的 `codexBridge` 配置。临时调试时也可以继续使用环境变量覆盖，例如 `AI_STRATEGY_CODEX_MODEL`、`AI_STRATEGY_PROXY_PORT`。

## 内网服务器：切换本地 DS 模型

如果内网 DS 服务提供 OpenAI 兼容接口，只需要改 `basic_data/config/模型服务配置.js`：

```js
window.__AI_STRATEGY_LOCAL_CONFIG__ = {
  enabled: true,
  provider: "inner-ds-openai-compatible",
  endpoint: "http://10.0.0.8:8000/v1/chat/completions",
  model: "deepseek-r1",
  timeoutMs: 90000,
  mode: "hybrid-parse",
  apiKey: "",
  headers: {},
  rateLimitBackoffMs: 60000,
  responseFormat: true
};
```

内网 DS 直连模式不需要启动 Codex 桥接脚本。需要确认 DS 服务允许页面所在域名跨域访问；如果浏览器报 CORS 错误，需要在内网 DS 网关上允许报表页面域名，或在内网服务器上加一个本地转发代理。

## 字段说明

- `enabled`
  - 是否启用模型解析。
  - `false`：只使用本地规则解析，不请求模型。

- `provider`
  - 页面展示用的模型服务名称。
  - 当前电脑建议保留 `"codex-cli-local-proxy"`。
  - 内网 DS 可填写 `"inner-ds-openai-compatible"`。

- `endpoint`
  - OpenAI 兼容接口地址，必须是 `/v1/chat/completions`。
  - 当前电脑 Codex 桥接：`"http://127.0.0.1:8787/v1/chat/completions"`。
  - 内网 DS 示例：`"http://10.0.0.8:8000/v1/chat/completions"`。

- `model`
  - 请求接口时传给后端的模型名。
  - 当前电脑 Codex 桥接默认：`"gpt-5.4-mini"`。
  - 内网 DS 示例：`"deepseek-r1"`、`"deepseek-v3"`，以你们本地服务实际暴露的名称为准。

- `timeoutMs`
  - 浏览器等待模型返回的超时时间，单位毫秒。
  - 内网 DS 推理较慢时建议 `90000`，前端最大限制为 `120000`。

- `mode`
  - 建议保留 `"hybrid-parse"`。
  - 含义：先用本地规则解析，再让模型补充复杂中文自然语言意图。
  - 可设为 `"local-only"` 或 `"off"`，表示不请求模型。

- `apiKey`
  - 内网接口需要 Bearer Token 时填写。
  - 不需要鉴权时保持空字符串。
  - 注意：该文件会随静态页面一起部署。多人可访问的内网环境，优先使用无密钥内网网关或服务端代理，不建议把真实密钥写进静态目录。

- `headers`
  - 额外 HTTP 请求头。
  - 示例：`{ "X-API-Key": "xxx" }`。

- `rateLimitBackoffMs`
  - 模型接口限流或失败后，页面暂停再次请求模型的时间，单位毫秒。

- `responseFormat`
  - 是否请求模型按 JSON object 返回。
  - 大多数 OpenAI 兼容服务支持；如果本地 DS 网关不支持 `response_format`，改为 `false`。

- `codexBridge`
  - 仅当前电脑 Codex 桥接脚本读取。
  - 内网 DS 直连时可以忽略。
  - 可配置端口、Codex 模型名、推理强度、桥接请求超时、并发数等。

## 迁移检查

1. 把整个结果目录同步到内网服务器。
2. 修改 `basic_data/config/模型服务配置.js`。
3. 用浏览器打开 `basic_data/ai-strategy.html`。
4. 页面顶部模型状态应显示新的 `model @ endpoint`。
5. 输入一句复杂中文筛选条件，例如“找近一年收益大于10%、最大回撤小于8%、不含黄金的稳健策略”，确认结果区显示“模型 xxx 已辅助解析”。
